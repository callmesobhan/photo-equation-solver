# Licensing: how to ask for a licence

Photo Equation Solver is proprietary software. Its source is public so that you can read it and try it; using it
beyond a trial needs a licence from the author. This page says what needs a licence and how to ask for one.

It is a summary. If it differs from [`LICENSE`](LICENSE), the `LICENSE` and any written agreement with the author win.

## What is free and what needs a licence

| You want to... | Licence needed? |
|---|---|
| Read the source code and the documentation | No |
| Try it for up to 30 days on your own devices, only to decide whether to buy a licence | No |
| Run its tests as part of that trial | No |
| Keep using it after the 30 days | **Yes** |
| Use it for teaching, assessment or grading (even in the first 30 days) | **Yes** |
| Use it for client work, in a business or in an institution (even in the first 30 days) | **Yes** |
| Build it into your own app, tool or product (for example with the library in `mcp-server/`) | **Yes**, and a written agreement: see below |
| Copy or share it, publish a modified version, offer it as a service or API, or use it to train or build a competing product | Not allowed without the author's written permission |

This follows sections 2, 3 and 5 of the `LICENSE`.

## What a licence gives you

Unless your agreement says otherwise, a licence is personal, non-exclusive, non-transferable and not sublicensable.
It lets you use the software, unchanged, on devices you own or control, for your own use (section 4 of the `LICENSE`).

Other arrangements, for example for a class, a team or an institution, can be discussed. There is no published price
list yet: price and terms are agreed with the author, case by case.

## How to ask

1. **Open a licence request:**
   [new licence request](https://github.com/callmesobhan/photo-equation-solver/issues/new?template=licence-request.yml).
   It is a short form.
2. **Tell the author** what you want to use it for, which edition (the phone skill for Google AI Edge Gallery, the
   local-model package, the agent package or MCP server, or the command line), how many people or devices, and
   roughly for how long.
3. **Do not post private details** in the public issue: no email address, phone number, postal address or payment
   details. The author will reply in the issue and, if needed, arrange a private way to continue.
4. **Wait for a reply.** This is a one-person project and there is no guaranteed response time; it can take days.
5. **A licence starts when the author confirms it in writing** (a reply on the issue is enough). If payment is part
   of the agreement, it is arranged privately once the terms are agreed. Nothing is paid through this page.

You can use the same route to ask for permission to do something the `LICENSE` does not allow, for example to include
the software in your own product. Building it into a product or service is not part of an ordinary licence (section 5 of
the `LICENSE`); say in the request what the product is, who uses it and how the software is delivered to them.

## If you found the skill in a marketplace

A text-only listing in a skill marketplace carries only instructions for an agent. The engine those instructions use
is a separate program, which this page and the `LICENSE` cover.
